# مواصفات المنتج — «آخر استخدام»

**الشعار:** لا تدع أغراضك تُنسى
**الهدف:** مساعدة الأفراد والأسر على معرفة ما يملكون، واستخدامه قبل أن يتلف أو يُنسى، واتخاذ قرارات مسؤولة بشأن ما لا يحتاجونه.

## الصفحات

| الصفحة | الملف | الوصف |
|---|---|---|
| البداية | `index.html` | تعريف بالقيمة والفوائد وطريقة العمل. زر «ابدأ الآن» يوجّه إلى اللوحة أو الدخول حسب الجلسة. |
| الدخول والتسجيل | `login.html` | تبويبان. التسجيل يطلب الاسم واسم المستخدم وكلمة المرور فقط، دون بريد أو جوال أو رمز تحقق. |
| لوحة التحكم | `dashboard.html` | الأغراض النشطة، ما يحتاج انتباهك، التنبيهات الجديدة، مؤشر الاستخدام، الأغراض المُنقذة، الصلاحية القريبة، قلة الاستخدام، أقرب التذكيرات، التوزيع حسب التصنيف، وإجراءان سريعان. |
| أغراضي | `items.html` | بطاقات أو جدول، وبحث عربي يتجاهل الهمزات والتشكيل، وتصفية بالتصنيف والحالة، وترتيب. الفلاتر محفوظة في الرابط. |
| تفاصيل الغرض | `item.html?id=` | البيانات، الحالة، أسباب الانتباه، اقتراح قابل للتجاهل، أزرار القرار، سجل الاستخدام، التنبيهات المرتبطة، وسجل الأثر. |
| إضافة / تعديل | `item-form.html[?id=]` | نموذج موحد مع تحقق فوري ورسائل عربية، وصورة تُصغَّر في المتصفح ويمكن إزالتها أو استبدالها. |
| التنبيهات | `notifications.html` | تبويبات حسب الحالة، وتصفية بالنوع، وتعليم كمقروء أو إغلاق، و«فحص التذكيرات الآن». |
| الإعدادات | `settings.html` | المهل الافتراضية، وطريقة العرض، والاسم، والبيانات التجريبية، وقنوات الإشعار (المعطّل منها موضح)، ومصدر البيانات. |

كل صفحة لها حالات تحميل وفراغ وخطأ مع زر «إعادة المحاولة»، وكل حذف يمر بحوار تأكيد داخل الواجهة.

## مسارات المستخدم

1. **أول مرة:** البداية ← إنشاء حساب ← لوحة فارغة ← «أضف أول غرض» أو «تحميل البيانات التجريبية».
2. **الاستخدام اليومي:** اللوحة ← «تسجيل استخدام» ← اختيار الغرض ← تحديث `last_used_at` وإضافة سجل وإغلاق تنبيه قلة الاستخدام تلقائيًا.
3. **معالجة تنبيه:** التنبيهات ← «فتح الغرض» ← قراءة الاقتراح ← تسجيل قرار (احتفظت / أعدت استخدامه / أصلحته / استبدلته / أهديته / تبرعت / تخلصت).
4. **التنظيم:** أغراضي ← بحث أو تصفية ← تعديل أو حذف.

## قواعد التنبيه

يُحسب «اليوم» بتوقيت **Asia/Riyadh**. الطوابع الزمنية تُخزن بصيغة `timestamptz` (UTC)، والتواريخ اليومية بصيغة `date`.

| النوع | الشرط | موعد الاستحقاق (`due_date`) |
|---|---|---|
| `expiry` | `expiry_date - اليوم ≤ مهلة التنبيه` (يشمل المنتهي) | `expiry_date` |
| `unused` | `اليوم - أساس الاستخدام > حد قلة الاستخدام`، والغرض غير منتهٍ وغير تالف | `أساس الاستخدام + الحد` |
| `replacement` | `موعد الاستبدال - اليوم ≤ مهلة التنبيه` | موعد الاستبدال |

- **أساس الاستخدام:** `last_used_at`، وإلا `purchase_date`، وإلا تاريخ الإضافة.
- **أساس الاستبدال:** `purchase_date`، أي بداية عمر الوحدة الحالية، وإلا آخر استخدام، وإلا تاريخ الإضافة. سبب الاختيار: لو حُسب من آخر استخدام لتأجّل موعد استبدال الفلتر مع كل استخدام. قرار «استبدلته» يضبط تاريخ الشراء على اليوم فتبدأ دورة جديدة.
- **المهل:** قيمة الغرض إن وُجدت، وإلا الإعداد العام (قلة الاستخدام ٦٠ يومًا، الصلاحية ١٤ يومًا، الاستبدال ٧ أيام).
- **منع التكرار:** مفتاح التنبيه `(item_id, type, due_date)` فريد. يُنشأ مرة واحدة ولا يعود إن أغلقه المستخدم. يتغير المفتاح فقط إذا تغيّر موعد الاستحقاق، مثل استخدام جديد ثم مرور المهلة مجددًا.
- **الإغلاق التلقائي:** أي تنبيه مفتوح لم يعد مستحقًا (بعد استخدام أو تعديل أو أرشفة) يُغلق بـ `closed_reason = 'resolved'`.
- **متى يُفحص:** بعد كل إضافة أو تعديل أو استخدام أو قرار للغرض المعني، وعند فتح اللوحة والأغراض والتنبيهات (مرة في الدقيقة على الأكثر لكل مستخدم)، ويدويًا، وعند بدء الخادم.

## التوصيات (اقتراحات لا أحكام)

| الحالة | الاقتراح |
|---|---|
| الغرض معطّل | أصلحه |
| تالف أو منتهي الصلاحية | تخلّص منه بطريقة مناسبة، وللأدوية: اسأل الصيدلية |
| قليل الاستخدام ومن المستهلكات | استخدمه أو أهدِه قبل أن يتلف |
| قليل الاستخدام لأكثر من ضعف الحد | أهدِه أو تبرّع به |
| قليل الاستخدام | أعد استخدامه |

يمكن تجاهل الاقتراح، فيُخفى لذلك الغرض والاقتراح على هذا الجهاز.

## أثر القرارات

| القرار | الأثر على الغرض |
|---|---|
| احتفظت به | يغلق تنبيه قلة الاستخدام الحالي |
| أعدت استخدامه | يحدّث آخر استخدام ويضيف سجلًا |
| أصلحته | حالة الغرض: صالح |
| استبدلته بجديد | تاريخ الشراء وآخر استخدام = اليوم، والحالة: صالح |
| أهديته / تبرعت به / تم التخلص منه | ينتقل إلى الأرشيف ويُغلق ما يخصه من تنبيهات |

**«أغراض أُنقذت من النسيان»** = قرارات (إعادة استخدام، إصلاح، إهداء، تبرع) + تنبيهات قلة استخدام أُغلقت لأن الغرض استُخدم فعلًا.
**«مؤشر الاستخدام»** = نسبة الأغراض النشطة المستخدمة ضمن مهلتها.

## اللغة والمظهر

- **اللغتان:** العربية (افتراضية، من اليمين لليسار) والإنجليزية (من اليسار لليمين). تُحفظ اللغة في المتصفح، وتُرسل للخادم في الترويسة `X-Lang`.
- **نصوص التنبيهات:** تُعرض بلغة الواجهة الحالية، لأنها تُبنى من نوع التنبيه وتاريخ استحقاقه.
- **المظهر:** فاتح أو داكن أو حسب إعداد الجهاز. يُطبَّق قبل ظهور الصفحة حتى لا يحدث وميض.
